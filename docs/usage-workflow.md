# Usage Workflow (Planned)

The command interface is not implemented yet. This document describes the intended workflow, not available commands.

1. Supply a public upstream Git URL and exact revision.
2. Run static inspection.
3. Review technology and licence evidence.
4. Resolve rights questions.
5. Create or select a branding profile.
6. Generate a dry-run change plan.
7. Review and approve the plan.
8. Apply changes in a disposable working copy.
9. Run adapter tests and upstream build.
10. Review diff, attribution bundle, and provenance report.
11. Manually approve distribution or deployment.

Stop if the project is unsupported or evidence is insufficient.
